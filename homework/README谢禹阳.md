# Project Title:学生绩点计算工具
####    这个程序的主要特点和功能：
    1.采用了常见的绩点换算标准（90 分及以上为 4.0，85-89 分为 3.7，以此类推）
    2.支持输入任意数量的课程，每输入一门课程后会询问是否继续
    3.对输入进行了有效性检查，确保学分是正整数，成绩在 0-100 之间
    4. 提供了清晰的文字提示，引导用户完成整个输入过程
    5. 计算并显示每门课程的绩点，以及最终的平均绩点输出结果保留两位小数，显示更规范
    使用时，只需按照程序的提示依次输入课程名称、学分和成绩即可，程序会自动处理所有计算并给出最终结果。

# Running the tests:项目测试
    1. 手动测试：直接运行程序，按照上述用例逐一生成输入，观察输出是否符合预期。
    2. 边界值分析法：重点测试分数区间的临界点（如 60 分、63 分、64 分等）和输入的极限值（0 分、100 分、1 学分等）。
    3. 等价类划分：将输入分为 “有效等价类”（如学分 1-10、成绩 60-100）和 “无效等价类”（如学分≤0、成绩 > 100），分别测试。

# Usage：使用方法
    启动程序后，会显示欢迎信息和使用说明，之后依次提示输入第 1 门课程的名称、学分（需输入正整
    数，若输入无效会提示重新输入）和成绩（需输入 0-100 之间的整数，若输入无效会提示重新输入），
    输入完成后会显示该课程的绩点并询问是否继续输入下一门课程，若输入 “y” 或 “Y” 则重复上述输
    入流程，若输入其他字符则结束输入，随后程序会显示总课程数、总学分和平均绩点，最后显示结束信
    息。
